⚠️ Vous voyez cette page ?
Cela signifie que vous avez ouvert index.html directement, ce qui cause l'erreur CORS.

🔧 Solutions pour résoudre l'erreur "Erreur réseau" :

Option 1 : Extension navigateur + Recharger

  1. Vérifiez que l'extension CORS est activée (icône colorée en haut à droite)
  2. Appuyez sur Ctrl + Shift + R (ou Cmd + Shift + R sur Mac) pour recharger complètement
  3. Retestez la connexion

Option 2 : Serveur local (Recommandé)

Double-cliquez sur :

  • Windows : LANCER_APPLICATION.bat
  • Mac : LANCER_APPLICATION.command

Si Python n'est pas installé, téléchargez-le ici :

📥 Télécharger Python

Option 3 : Utiliser un serveur en ligne

Je peux vous aider à déployer l'application sur un serveur gratuit (Netlify, GitHub Pages).

✅ Une fois que vous avez appliqué une solution :

  1. Rechargez cette page (ou ouvrez l'application depuis le serveur)
  2. Remplissez vos informations Odoo
  3. Cliquez sur "Tester la connexion"
  4. Si ça marche → Bravo ! 🎉
  5. Si ça ne marche pas → Voir "Diagnostic avancé" ci-dessous

🔍 Diagnostic avancé

Si rien ne fonctionne, vérifiez :

1. Votre URL Odoo est-elle correcte ?

  • ✅ Doit commencer par https:// (pas http://)
  • ✅ Doit se terminer par .odoo.com ou votre domaine
  • ❌ NE DOIT PAS avoir de / à la fin
  • Exemple correct : https://monentreprise.odoo.com
  • Exemple incorrect : http://monentreprise.odoo.com/

2. Pouvez-vous accéder à Odoo dans un autre onglet ?

Ouvrez un nouvel onglet et allez sur votre URL Odoo. Si vous ne pouvez pas vous connecter, c'est que :

  • Votre instance Odoo est hors ligne
  • Vous n'avez pas Internet
  • L'URL est incorrecte

3. Le nom de votre base de données est-il correct ?

Pour trouver le nom exact :

  1. Connectez-vous à Odoo dans votre navigateur
  2. Appuyez sur F12
  3. Cliquez sur l'onglet Console
  4. Tapez : odoo.session_info.db
  5. Appuyez sur Entrée
  6. Le nom affiché est le bon !

📞 Toujours bloqué ?

Si aucune solution ne fonctionne :

  1. Notez quelle solution vous avez essayée
  2. Faites une capture d'écran de l'erreur
  3. Ouvrez la Console (F12) et regardez s'il y a des erreurs en rouge
  4. Contactez le support avec ces informations
