# Assets

Ce dossier contient les ressources de l'application.

## Images requises

Pour que l'application fonctionne correctement, vous devez ajouter les images suivantes :

- `icon.png` - Icône de l'application (1024x1024 px)
- `splash.png` - Écran de démarrage (1242x2436 px)
- `adaptive-icon.png` - Icône adaptative Android (1024x1024 px)
- `favicon.png` - Favicon pour le web (48x48 px)

Vous pouvez utiliser des outils comme :
- [App Icon Generator](https://appicon.co/)
- [Figma](https://figma.com/)
- [Canva](https://canva.com/)

Ou créer vos propres images avec votre logo/design.
