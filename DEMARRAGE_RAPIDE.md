## ❌ Ça ne marche pas ?

### Problème : Je ne trouve pas le fichier ZIP
**Solution :** Regardez dans votre dossier **Téléchargements** (Downloads)

### Problème : Le fichier index.html ne s'ouvre pas
**Solution :** Faites clic droit → Ouvrir avec → Chrome (ou Firefox)

### Problème : "Erreur de connexion"
**Solution :** Vérifiez que :
- Vous avez Internet
- Votre URL commence par `https://`
- Votre mot de passe est correct

### Problème : "Base de données introuvable"
**Solution :**
- Essayez avec juste le nom (sans .odoo.com)
- Essayez en minuscules, sans espaces
- Contactez votre administrateur Odoo
